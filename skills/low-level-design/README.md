# Low-level design

Use this skill for object-level design of a bounded system or for an interactive design drill. It focuses on requirements, invariants, object responsibilities, and the calls and state changes in one representative operation. A short diagram and a runnable seam make the proposed model easier to check.

A worked design asks for missing rules before assigning ownership. A drill introduces requirements one at a time and gives feedback on the participant's current model before adding another constraint. The guide keeps design sketches separate from code that was actually run.

This skill does not cover service topology, replication, or scale planning. It does not assume a particular language, framework, or diagram renderer.
