# De-slop

Use this skill to revise existing prose that sounds formulaic or conspicuously AI-written. It cuts filler, repeated framing, and unsupported emphasis while keeping the writer's facts, terminology, caveats, and chosen voice. It does not make every document terse or technical: a personal note can stay warm, and a technical note can stay precise.

Give the agent the draft, its audience, and any tone or wording that must remain. Ask for a revision, not an invented argument. The skill checks the revised text against the original and flags passages whose meaning cannot be resolved safely. For a technical specification whose main goal is a consistent dry register, use `plain-technical-prose` instead. This guide does not verify claims or determine whether a person or model wrote the original.
